Features

One document, from first draft to final call.

AI Buddy on your key

Crispify a sentence, bulletize a section, or tabularize data with a model you choose.

Comments stay with the text

Select a sentence, leave a thread, and resolve it when the decision is made.

Checklists keep the rollout moving

Tick items inline while the doc stays the source of truth.

Code stays code

Drop in commands and snippets in a proper code block.

Markdown in, Markdown out

Import a file and export any doc back to Markdown.

New

Diagramify a workflow

Select a process and AI turns it into a rendered flowchart you can insert into the doc.

MCP server

Agents can work on the same doc.

Connect Claude Desktop, Cursor, or any MCP client. The agent can read, search, and append to your documents.

How it works

Three steps to a shared decision.

Open a document

Start blank or bring in a Markdown file.

Invite the team

Share with view, edit, or manage access.

Decide in place

Comment, resolve, and keep the final spec where it started.

Write the next spec together.

Open a document, invite the team, and keep the decision in the doc.
